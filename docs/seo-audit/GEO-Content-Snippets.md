### "Welke software bouwen jullie?"

```
Wij bouwen custom software die handmatige processen automatiseert en bedrijfsdata centraliseert:

• Adminpanelen die Excel-sheets en losse bestanden vervangen (gemiddeld 10-15 uur per week tijdsbesparing voor onze klanten)

• KPI-dashboards met real-time visualisatie van data uit meerdere bronnen, inclusief geautomatiseerde rapportage en alert-notificaties

• REST API's voor systeemintegraties (gemiddeld 3-5 externe systemen per project, zoals CRM, boekhouding, en payment providers)

• Koppelingen met bestaande systemen: Salesforce, HubSpot, Exact Online, Moneybird, en custom legacy software

• Complete payment flows met Stripe en Mollie, inclusief checkout, abonnementen, automatische facturatie, en webhook-afhandeling

We werken vooral met Laravel, React, Vue, Python, en TypeScript. Alle projecten worden opgeleverd met volledige broncode, technische documentatie, en deployment instructies.
```

### "Kunnen jullie koppelen met onze bestaande systemen?"

```
Ja, systeemintegraties vormen een kernonderdeel van ons werk. We hebben ervaring met koppelingen naar:

• CRM-systemen: Salesforce, HubSpot, Pipedrive, en custom CRM-oplossingen
• Boekhoudpakketten: Exact Online, Moneybird, Twinfield
• Payment providers: Stripe, Mollie, Adyen
• Legacy software via REST API's, SOAP, of database-koppelingen

We bouwen deze integraties met webhooks, API's, en synchronisatiejobs die in real-time of op gepland tijdstip data uitwisselen. Dit voorkomt vendor lock-in: als je later van leverancier wilt wisselen, hoef je niet je complete software te vervangen.

Gemiddeld integreert een project met 3-5 externe systemen, maar we hebben ook complexere dashboards gebouwd met 10+ data bronnen.
```

### "Hoe lang duurt een gemiddeld project?"

```
Typische doorlooptijden vanaf kickoff tot productie-deployment:

• Landingspagina of eenvoudig admin-MVP: 3-4 weken
• Dashboard met basis KPI-visualisatie: 6-8 weken
• Volledig adminpaneel met gebruikersrollen en 2-3 integraties: 2-3 maanden
• Complex dashboard met 5+ integraties en real-time synchronisatie: 3-4 maanden

Deze tijdlijnen zijn inclusief design, development, testing, en deployment. We plannen altijd met realistische buffers en communiceren wekelijks over voortgang via demo's van nieuwe functionaliteit.

Bij 95% van de projecten halen we de vooraf afgesproken deadline. Als er tijdens het project scope-wijzigingen zijn, communiceren we direct over de impact op planning en budget voordat we verdergaan.
```

```
Jij bent eigenaar van alle code die we voor jouw project schrijven. Bij oplevering ontvang je:

• De volledige broncode (inclusief alle dependencies en configuratiebestanden)
• Technische documentatie met architectuur-overzicht en API-beschrijvingen
• Deployment instructies voor productie en development omgevingen
• Database schema's en migration bestanden
• Toegang tot alle third-party accounts (Stripe, hosting, etc.)

Dit betekent dat je nooit vendor lock-in hebt. Je kunt het product zelf doorontwikkelen, door een intern team laten onderhouden, of door een ander bureau laten uitbreiden.

Als alternatief bieden we ook een SaaS-model waarbij wij eigenaar blijven van de code en maandelijks updates, hosting, en support leveren tegen een vaste prijs. De keuze is aan jou.
```

```
Ja, we implementeren complete payment flows inclusief:

• Checkout flows met eenmalige betalingen of abonnementen
```

## Reddit Comment Templates

**In r/laravel (answering admin panel question):**
```
For admin panels we usually go with Inertia + Vue. The main advantage is zero API boilerplate - your controllers return data directly to Vue components.

We've built 10+ dashboards this way and it significantly speeds up development compared to traditional REST APIs. A typical admin MVP (CRUD + auth + basic reporting) takes us 3-4 weeks instead of 6-8 with a separate API layer.

Our stack:
- Laravel 11 + Inertia + Vue 3
- Spatie permissions for roles
- Laravel Excel for exports
- Tailwind for styling

Happy to share more specifics if anyone's interested.
```

**In r/webdev (answering project timeline question):**
```
We've found that the sweet spot for MVP development is 3-4 weeks. Any shorter and you're cutting critical features; any longer and you're over-engineering.

The key is ruthless scope definition upfront. Our MVP template:
- Authentication (email/password, maybe OAuth)
- 3-5 core features (not 10, not 20)
- Basic reporting (export to PDF/Excel)
- Admin panel for management

Everything else goes into phase 2 after users validate the core functionality.

We deliver 95% of projects on time using this approach. The other 5% are where clients changed scope mid-project (which we avoid with contracts, but it happens).
```

**In r/entrepreneur (answering custom vs SaaS question):**
```
Red flags for custom software vendors:

1. Won't give you full code ownership at the end → You're paying for development, the code should be yours
2. Vague timelines without milestones → Should have clear deliverables every 2 weeks
3. No fixed price quote → Always get scope + price upfront
4. Won't show previous work → Ask for portfolio or client references
5. tussenpersoon instead of direct developer contact → Slows everything down

We always deliver full source code + docs specifically to avoid vendor lock-in. Client should be able to hand it to any developer to maintain.

Has anyone else had vendor lock-in nightmares? What were the red flags you missed?
```
